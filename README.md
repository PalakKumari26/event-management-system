# 🎫 Event Management System

A full-stack Event Management System built with React.js, Java, and MySQL.  
Users can register, log in, explore upcoming events, and register for available seats.

## ✨ Features

- 👤 User Registration & Login
- 📅 View Upcoming Events
- 🎟️ Event Registration
- 💺 Live Available Seat Updates
- 🚫 Prevent Duplicate Registration
- 🗄️ MySQL Database Integration
- 🔗 Java Backend REST APIs

## 🛠️ Tech Stack

Frontend: React.js, Vite, JavaScript, CSS  
Backend: Java, JDBC, HTTP Server  
Database: MySQL  
Tools: Git, GitHub, VS Code

## 🔄 Application Flow

React Frontend → Java Backend → JDBC → MySQL
